# Text to Speech Synthesis Example

This Python script demonstrates basic text-to-speech synthesis using the pyttsx3 library. It shows how to convert text into spoken audio and optionally select different voices available on the system.

## Language

`python`

## How to Run

1. Install the library: pip install pyttsx3
2. Run the script: python tts_demo.py
